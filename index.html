02

方法论：五维质量指标体系

同一把尺子，同时度量模型输出的质量与业务价值
CORRELATION

重测信度

同一原始输入下，多条模型输出结论之间的一致性程度。

判断标准：以语义核心含义对齐为依据，不强制字面相同；多条输出可一致犯错，一致性不受事实对错影响。统计：踩分点计数。
FACTUALITY

事实准确性

输出与原文的匹配程度，不编造、不篡改、不歪曲。

判断标准：引用信息可溯源原文；区分“同向克制延伸”与“质变式过度解读”。统计：踩分点计数。
EXPLAINABILITY

可解释性

输出结构清晰，推理链路可追溯，读者能看懂结论从何而来。

判断标准：结论与支撑依据对应，关键分析有原文支撑，无突兀结论。统计：5 分制。
DEPTH

分析深度

是否完成有效信息提炼，多角度、双向看待问题。

判断标准：提炼核心矛盾与多方立场，不做浅层复述与片面判断。统计：5 分制。
USABILITY

业务可用性

产出结论、建议对下游业务是否具备实操价值。

判断标准：建议具体可落地、贴合业务场景，不产空泛套话。统计：5 分制。
TWO TRACKS

双轨统计口径

不同性质的指标用不同的统计方式，避免“一张表打天下”。

重测信度 / 事实准确性：踩分点计数（对错可枚举）。可解释性 / 分析深度 / 业务可用性：5 分制评分（需语义判断）。
设计要点：每一维都同时给出“判断依据、正误边界、典型错误场景”，让人工评审与机器评测共用同一套可执行标尺——这是自动化能成立的前提。
03

分层自动化评测框架

机器发现问题，人工确认问题，数据验证机器
自动化评测总体链路
1
模型生成输出原始评测对象
2
基础规则检测格式、字段、实体等确定性规则
3
LLM 自动质量评测语义级评分与判断
4
异常问题识别分类风险分级，标记待复核样本
5
人工复核复杂 / 疑似 / 边界问题
6
沉淀数据集与错误案例反馈回流，扩充标准库
7
评测标准迭代 · 验证 · 扩大覆盖持续闭环，扩大自动化范围
LEVEL 1

规则检测

明确、重复、规则化的问题（格式 / 字段 / 实体 / 时间戳），由程序直接判断，零人工成本。

LEVEL 2

AI 辅助评测

有标准但需要语义理解的问题，LLM Judge 全量初判，AI 评测 + 人工复核双轨保障。

LEVEL 3

人工判断

复杂、边界、高风险问题，交由人工终审，人工资源只集中在高价值判断上。

核心原则：机器负责“发现问题”，人工负责“确认问题”，数据负责“验证机器”。
04

评测标准与 Gold Set 标准数据集

自动化的基础不是智能代理，而是可执行、可落地的评测标准
错误案例→ 归类错误类型→ 拆解可落地判断条件→ 是否可程序判断→ 是否可 LLM 判断→ 确定自动化方式
判定标准清晰度

对错条件是否明确、错误样例可否枚举、边界是否清晰

语义推理依赖

仅格式 / 实体匹配，还是需要上下文理解与复杂推理

人工评审一致率

双人独立评审的分歧度，判断标准是否稳定客观

自动化等级判定方式人工角色典型场景
完全自动化机器直接判断无时间、目标达成度
AI 评测 + 人工复核AI 全量判断抽检 / 异常复核内容总结、访谈概要
AI 辅助评测AI 提供证据与初判最终判断言外之意、共识分歧
人工评测人工完成全量画像洞察、核心特质

Gold Set：标准数据集的建立

解决核心问题——如何验证 AI 评测判断是否可靠。由高质量正确案例、已确认错误案例、典型边界案例构成，全部附人工终审结论，用于计算 Precision、Recall、F1 与人工判断一致率。采用双人独立标注 + 专家仲裁机制，样本规模结合场景覆盖度、错误类型覆盖度与置信度共同确定。

任务边界：划定回答是否落在问题要求范围内
核心语义：判定必须回答的关键元素是否覆盖
可接受变体：语义一致性可接受的其他表述范围
事实边界：可合理概括，但不得引入原文不支持的
质量边界：区分“回答正确但不合格”的低质量输出
05

自动化评测 Agent

作品：数据标注 Skill + Prompt 诊断 Agent（B 端模型评测自动化工作流）

Agent 不是自动化评测的起点，而是体系跑通后的上层封装

  1. 评测标准体系稳定：五维指标、子业务维度、错误类型库定稿
  2. 高频错误模式充分归类，规则库完成多轮迭代验证
  3. 积累规模充足、质量可靠的 Gold Set 标准数据集
  4. 规则检测、LLM Judge 模块单独验证达标，效果指标合格
  5. 试点数据已验证明确的人效 / 成本收益，足以支撑工具化投入
STEP 01
底层能力封装

把已验证的规则检测、LLM Judge、异常识别分类、错误标签输出封装为内部能力单元，不重复造评测逻辑。

STEP 02
流程编排

原始数据输入 → 规则层过滤 → LLM 层评测 → 风险分级标记，输出问题位置、错误类型与评测打分。

STEP 03
人工复核回流

Agent 输出承接人工复核反馈，复核结果自动回流，更新案例库与规则库，形成数据飞轮。

STEP 04
自身效果监控

跟踪 Agent 输出与人工终审的一致率，监控误判情况，保证自动化本身不失控。
